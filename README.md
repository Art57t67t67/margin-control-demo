# Margin Control

**Публичное демо EXCEL-002**

Margin Control анализирует CSV-таблицы цен и себестоимости и показывает:

- какие SKU находятся ниже целевой маржи;
- как изменилась маржа относительно базового периода;
- какую минимальную цену нужно поставить, чтобы вернуться к целевой марже;
- строки с ошибками и дубликатами, которые нельзя тихо включать в итог.

## Проверенный демо-результат

На тестовом наборе из 10 SKU:

- взвешенная маржа: **40,88%**;
- найден 1 товар ниже целевой маржи;
- **SKU-1007 / HDMI Adapter**: маржа **14,29%**;
- изменение против базового периода: **−30,71 п.п.**;
- минимальная цена для целевой маржи 25%: **4,80**.

[Открыть HTML-демо в репозитории](./index.html)

## Как работает

Инструмент запускается локально, принимает CSV и формирует отчёт в Markdown / CSV / JSON. Данные не отправляются во внешние сервисы.

Текущие ограничения: требуется Node.js 20+; прямое чтение `.xlsx` не реализовано — нужен CSV-экспорт.
