## О продукте Margin Control

Это существующий локальный инструмент анализа цен и себестоимости из CSV: маржа, наценка, изменение относительно базового периода, минимальная цена и отдельный список ошибочных строк/дубликатов. Данные обрабатываются локально.

Требования продукта: Node.js 20+, командная строка, CSV. Прямое чтение XLSX не реализовано. [HTML-файл примера](./index.html) сохранён в репозитории. [Проверить исходные данные и отчёт](./CASE_MARGIN_CONTROL.md).

Это публичная демонстрация и услуга по согласованному заданию. Платёжная витрина для самостоятельной покупки архива ещё не подтверждена; подтверждённых клиентских отзывов и продаж пока нет.
