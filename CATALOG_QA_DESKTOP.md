# Catalog QA Desktop — проверка товарных CSV без облака

**Windows-приложение для сверки собственных товарных карточек и поиска расхождений.** Данные обрабатываются локально; программа не подключается к кабинетам маркетплейсов, не отправляет ответы и не требует подписки на ИИ.

## Что уже реализовано в версии 1.1.0

- Сравнение двух карточек по введённым значениям: бренд, артикул производителя, модель, количество, комплектация, упаковка и другие поля.
- Пакетная проверка CSV до **1 000 пар** и **5 МБ**; поддерживаются UTF-8/Windows-1251, запятая, точка с запятой и табуляция.
- Отчёт JSON с конкретными совпадениями, расхождениями, пропущенными полями и ошибочными строками.
- Windows 10/11 x64; собранное приложение работает без установленного Python и без интернет-подключения.

**Ограничение:** это инструмент предварительного аудита, а не доказательство идентичности товаров. Каждая пара требует проверки человеком. Программа не угадывает неизвестные характеристики и не подменяет исходные сведения.
