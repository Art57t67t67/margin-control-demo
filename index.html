Margin Control

Инструмент для анализа CSV-таблиц цен и себестоимости: показывает товары ниже целевой маржи, изменение маржи и минимальную цену для возврата к цели.

Локально
данные не уходят в облако
CSV → отчёт
Markdown / CSV / JSON
Без подписки
Node.js 20+

Реальный демо-результат

На тестовом наборе из 10 SKU инструмент рассчитывает взвешенную маржу 40,88% и обнаруживает SKU-1007 / HDMI Adapter с маржой 14,29%, изменением −30,71 п.п. и минимальной ценой 4,80 для целевой маржи 25%.

Статус

Это публичное демо существующего EXCEL-002. Подтверждённых продаж, отзывов или пользовательской статистики пока нет — страница этого не утверждает.

Ограничения: CSV only; прямое чтение .xlsx не реализовано.
